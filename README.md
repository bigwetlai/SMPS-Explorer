# SMPS CSV Explorer

**CREATED BY Claude!! Use with caution and expect error**

Read, check and plot particle size distributions exported from **TSI AIM 9** and the
**TSI SMPS** software (scanning mobility particle sizer / DMA + CPC) — in the browser,
without installing anything.

- One self-contained HTML file: open it by double-click, offline, or from GitHub Pages.
- Your data never leaves your computer: files are read and processed inside the browser.

## Features

- **Reads both export layouts**: AIM 9 "scans as columns" (Windows-1252, 64 channels/decade)
  and TSI SMPS "scans as rows" (UTF-8, 128 channels/decade). Encoding, layout, bin width
  (dlogDp) and date format are detected per file.
- **File check strip**: software, channels/decade, a totals check
  (Σ dN/dlogDp · dlogDp vs. the file's total concentration for every scan), date format
  (with override), time span, corrections, warnings.
- **Data matrix**: one checkbox per scan = use it. Flags suggest bad scans (all-zero,
  duplicate scan number, spikes/dips, size shifts, flow changes); nothing is removed
  until you uncheck it. *Expand* shows times, totals, medians, thumbnails and flag text.
- **Charts**: size distribution (dN/dlogDp or dN/dDp) and a bar chart of any per-scan value,
  with journal-style presets and PNG / SVG / PDF export at a chosen size and DPI.
- **Average groups**: pick scans from one or several files → one averaged curve and one bar.
  Auto-grouping, drag to reorder, checks that size bins and inversion settings match.
- **Group statistics**: mean, SD, CV, SE, 95 % CI of any per-scan value, plus total, median,
  mean diameter, geometric mean, GSD and mode of each group's averaged distribution —
  computed like the instrument software (will be in [docs/statistics.md](docs/statistics.md)).
- File order adjustable (drag the file tabs).

## Use it

**Option 1 – open the web page.** If GitHub Pages is enabled for this repository, the tool
is at `https://<user>.github.io/<repository>/`. Drag your CSV exports onto the page.

**Option 2 – download.** Get `SMPS_CSV_Explorer.html` from the
[Releases](../../releases) page and open it in Chrome, Edge or Firefox. It works offline.

**Option 3 – build it yourself** (needs [Node.js](https://nodejs.org) 22 or newer):

```bash
npm ci            # install the exact dependency versions
npm test          # unit tests
npm run build     # → dist/index.html
```

### Exporting from the instrument software

Export the scans from AIM 9 or the TSI SMPS software as a comma-separated (CSV) file,
with concentrations as dN/dlogDp and number weighting. Several files can be loaded at once.
Both decimal points and the default column layouts of each program are expected.

## Repository layout

```
src/                 application source (bundled into one HTML file)
scripts/build.mjs    build → dist/index.html
scripts/make-fixtures.mjs   generates the synthetic test files
tests/unit/          unit tests (node --test)
tests/browser/       end-to-end tests in headless Chromium (Playwright)
tests/fixtures/      synthetic AIM 9 / SMPS example exports (no real measurement data)
docs/                documentation
.github/workflows/   CI, GitHub Pages deployment, release builds
```

## Test data

The files in `tests/fixtures/` are **synthetic**: generated by `scripts/make-fixtures.mjs`
in the exact format of the real exports (log-normal size distributions with counting
noise, serial numbers zeroed). They are safe to share and can also be used to try the tool.
